## ⚖️ Rules & Accountability Regulations
To prevent the "I finished" lie, all students must abide by the following automated system rules:

*   **No Manual Passes:** A module is only marked "Done" when the system logs actual time spent active on the unit page.
*   **Activity Transparency:** Admins can view complete access logs (exactly *who* opened *what* resource and *when*).
*   **The AI Nudge:** If a student sets a learning goal and misses their timeline, the AI system will trigger a high-priority alert/alarm.
*   **Community Support:** All members must actively participate in the Telegram-style group chat and attend live helper sessions.
